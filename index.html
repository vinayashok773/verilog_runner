Scope and limitations

Automatic generation supports ANSI and non-ANSI scalar / packed-vector ports, numeric parameters, signed buses, multiple modules and multiple clocks. Unsupported declarations produce an error instead of guessed widths. Use a custom testbench for advanced top-level types or parameter syntax. Simulation models Verilog RTL behavior, not physical FPGA propagation timing. Vendor IP requires compatible simulation models. Run only trusted HDL: this local runner is not a security sandbox. No simulation data is sent online.
